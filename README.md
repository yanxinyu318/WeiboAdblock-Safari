# 微博去广告 · Safari 扩展（自签版）

一个 iPhone Safari 扩展：打开微博网页版 / 触屏版时，自动移除信息流里的广告、热推、推广微博，以及热搜里的推广条目。

## 它能干什么

- 删带「广告」「热推」「推广」角标的微博整条卡片
- 删热搜里带「荐」的推广条目
- 往下刷加载出来的新广告也会跟着删（一直在监听）
- 右下角有个小气泡，显示已屏蔽几条；点一下暂停，再点一下恢复；双击藏起来

## 它不能干什么

- 微博 App 里的广告管不了（那是 App 内部的，只能走网络层规则）
- 只在 Safari 里打开微博网页版 / 触屏版（weibo.com、m.weibo.cn）时生效

## 安装（自签）

1. 从 GitHub Actions 的 Artifacts 里下载 `WeiboAdblock-iOS-1.0.0.ipa`（未签名）。
2. 用你自己的证书自签安装（和以前 Beans / Kumone 的办法一样，免费证书 7 天有效，到期重新签一次）。
3. 装好后打开 App 看一眼说明，然后去「设置」>「Safari 浏览器」>「扩展」，打开「微博去广告」。
4. 点进「微博去广告」，把网站访问权限设为「所有网站」（实际只在 weibo.com / weibo.cn 上运行）。
5. 回到 Safari 打开微博，就行了。

## 隐私

扩展只在你自己的浏览器里隐藏广告展示，不改账号、不碰数据、不发任何请求。去广告逻辑在 `WeiboAdblockExtension/Resources/content.js`，可以自己打开看。

## 失效了怎么办

微博改版后角标文字或页面结构变了，扩展可能失效。判断方法：刷微博时广告又出来了，右下角气泡数字也不涨了。

- 先去「设置」>「Safari 浏览器」>「扩展」确认开关还开着、权限还是「所有网站」。
- 还不行就是微博改版了，等新版。提 issue 时附上失效那条微博的截图（角标长什么样）和你的 iOS 版本。
